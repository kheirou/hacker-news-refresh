## [1.0.0]

First release.

### Added
- Flat redesign of news.ycombinator.com: tabs, toolbar, date heading, short ages, optional fixed header.
- Five themes, Sans / Serif / bundled Inter type, text size, line spacing and page width.
- Table and list views with selectable columns and bold titles.
- Bookmarks (stories, comments, highlights, users) with JSON backup and restore.
- New-reply badges and marked new comments with step-through arrows.
- Selection popup, user hover cards, history panel, control pad, keyboard shortcuts, date picker.
- Popup with a master on/off switch; off restores the original HN exactly.
- Real-Firefox smoke test and Playwright suite.
